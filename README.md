# next-cache-rce-check

Standalone offline evidence checker for the Next.js `use cache` typed-array remote-code-execution advisory [GHSA-673q-mjm6-r5xr](https://github.com/vercel/next.js/security/advisories/GHSA-673q-mjm6-r5xr).

Implementation is being prepared under [CompleteTech-LLC/node2shell-check#5](https://github.com/CompleteTech-LLC/node2shell-check/issues/5), part of the [exploit-specific checker roadmap](https://github.com/CompleteTech-LLC/node2shell-check/issues/2).

Python 3.10+, standard library only, offline assessment, no exploit payloads. Each exploit has its own independent repository. This repository is dedicated to GHSA-673q-mjm6-r5xr.
